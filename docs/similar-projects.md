# GitHub 相似项目检索

检索日期：2026-09-10。使用 GitHub 仓库搜索（`codex pet`、`codex quota pet`）和 GitHub 网页检索，并阅读各项目 README。下面依据本次读取到的公开说明，不对未描述的功能作推断；这不是穷尽列表。

| 项目 | 平台与方式 | 与 Momo 的关系 |
| --- | --- | --- |
| [Quota Buddy](https://github.com/Tedhong95/Quota_Buddy) | Windows 10/11；在官方 Codex 宠物下方附加周额度、可用重置次数与到期信息，可跟随宠物移动 | 同属 Windows 宠物额度显示；Momo 自带 VPet 角色，使用头顶气泡，常驻显示 credits 余额 |
| [Codex Pet Dock](https://github.com/hjxccc/codex-pet-dock) | Windows 11；为官方宠物附加底座，显示周剩余和本地日志估算的周 Token，用详情卡展开更多数据 | 都把额度融入宠物；Momo 使用独立萌系角色、摸头与专注互动，不统计本地对话 Token |
| [codex-pet-limit-rings](https://github.com/petergpt/codex-pet-limit-rings) | macOS；跟随官方宠物绘制短窗口和周额度两个圆环，悬停查看数值 | 相同的常驻额度思路，表现为环形覆盖层；Momo 是 Windows 文字气泡 |
| [Black Hole Codex Quota Indicator](https://github.com/danya-kim99/codex-quota-pet) | macOS 14+、Apple Silicon；独立像素黑洞，形态随额度变化，悬停看准确值，提供趋势图 | 同属独立额度桌宠；角色、美术、平台及信息呈现不同 |
| [Codex Quota Pet](https://github.com/HZGuoo/codex-quota-pet) | macOS 13+；菜单栏加桌面额度球，通过本机 App Server 显示多窗口额度、任务状态和通知 | 额度读取和桌面常驻用途相近；Momo 当前重点为 Windows 萌系角色与简洁额度泡泡 |
| [CodexBar](https://github.com/steipete/CodexBar) | macOS 菜单栏额度工具，支持 Codex 等多个编码服务 | 额度监控功能相近，主要界面是菜单栏；可参考多服务支持，但不属于相同的角色动画表现 |

结论：GitHub 已经存在多个「Codex 宠物 + 额度显示」项目，包含 Windows 实现。因此不将此项目描述为首创。Momo 的具体组合是 Windows WPF 独立桌宠、VPet 萌系序列动画、160 × 100 头顶气泡、周额度与 credits 常驻、摸头 / 休息 / 专注计时。

上述项目仅作为检索与对照来源；本次实装没有复制其代码。Momo 的第三方角色素材来源见 [VPet 授权](../licenses/VPet-Animation-License.zh-CN.md)。

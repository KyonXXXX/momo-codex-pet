# 自动购买补充（本地 2.3.0-local）

规则：五项养成指标严格低于 60 时触发，默认开启且可以在互动面板关闭。最低指标优先；能恢复到 60 的道具按最低价格选，无法恢复到 60 时按恢复量／价格选。仅使用真实商店的可负担、无负面养成指标效果道具。每 30 秒最多一件；买不起等待；工作、专注、休息继续，手动投喂和退出期间不自动购买。

数据与生命周期：复用 PetLife.Feed 完成一次同步扣费和补充，立即原子保存设置。AutoCareEnabled 对旧存档默认开启，显式关闭保留；不改已有金币、指标和每日额度计算。测试模式不自动运行真实时钟购买，组件测试通过同一运行时入口验证交易。

验证：38 项自检（含真实 Codex 额度读取）全部通过，包含阈值、选品、费用、金币不足与恢复、开关序列化、重复调用、负面道具过滤、实际商店五指标覆盖。47 项相关界面与组件检查全部通过，包含真实道具购买、活动与专注保留、手动投喂阻塞和取消、开关事件、重新启用购买，以及已有日额度显示。互动面板截图人工核验，开关与最近购买记录可见。

命令：Momo.exe --capture artifacts/auto-care.png --demo --daily-only --auto-care-test。该捕获模式在相关检查与截图后退出，不重复已知无关的完整爬墙几何测试。

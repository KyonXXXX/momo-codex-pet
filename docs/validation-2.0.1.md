# 2.0.1 动画表现修复验证

- 提起锚点直接读取已固定版本的官方 `touch.raisepoint`，普通三种状态为 `(290,128)`，生病为 `(225,115)`，按 500×500 原始坐标缩放。
- 提起由鼠标捕获驱动，画面中的锚点对齐屏幕鼠标；动态/静态切换沿用锚点。释放或失去鼠标捕获后结束拖动并检查屏幕边界。
- 已删除底部三按钮及旧摸摸/休息快捷处理。专注通过角色右键菜单开始/结束。原生 VPet 触摸区域和睡觉互动继续保留。
- 爬左右墙、侧边躲藏时气泡移到内侧；顶部爬行和靠近顶部时移到下方。角色贴边不再由气泡宽度决定。
- 自动测试覆盖四种提起状态、两种体型、80%/100%/120% 缩放，左右墙/顶部/侧边躲藏的气泡开关与角色边界，专注菜单和鼠标捕获释放。
- 回归覆盖额度显示、气泡开关、喂食取消与结算、工作活动、实际窗口移动、触摸区域、动画图鉴。未改变原版图像资源和存档格式。
- 静态像素检查区分单帧实际边界和整组动画边界：整组预留动画摆动范围，避免逐帧挪动窗口。墙边动作另外检查角色贴边距离。
- 限制：当前 Windows 显示器/DPI 环境验证；不同 DPI 的多显示器切换未穷尽测试。
- 发布验证命令：`Momo.exe --self-test --live`；`Momo.exe --demo --capture artifacts/release-2.0.1.png --full-test --interaction-smoke`。侧向尖角也通过渲染像素取样检查，防止被布局裁切。

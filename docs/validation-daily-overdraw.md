# 今日超额显示（本地 2.2.1-local）

- 保留账号周余额推算规则，增加超过今天分配进度的透支量，不读取本机日用量。
- 100% 仍为周总额度的 1/7。剩余 3 天、周剩 25% 时超额 25%；周剩 10% 时超额 130%，下一额度日降为 30%。
- 超额时切换标签为「今日已超额」，文字与进度条转红；数字不封顶，条宽最多满格。刚好耗尽仍显示剩余 0%，极小正超额显示 <0.01%，避免误显示为 0%。
- 恢复额度、跨日抵扣完透支、周重置或数据失效时，清除旧超额标签；离线沿用原有同日缓存规则。

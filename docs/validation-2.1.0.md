# 2.1.0 今日额度进度

- 保留 160 px 宽度，卡片增高至 124 px。新增今日已用/剩余百分比及绿色进度条，无单独的日均建议文字行。左右墙/顶部避让同步适配。
- 每日参考量为剩余周额度除以剩余天数，最后不足一天时以一天为分母；每日用量按成功同步读数的增量统计，进度可超过 100%，但进度条限制为满格。
- 七组纯逻辑检查涵盖计算示例、动态剩余时间、离线冻结、重启序列化、重复/乱序样本、当地日期变化、隔夜缺口、周窗口/套餐变化、读数回退、超额、零额度、未知/过期数据及最后不足一天。
- 界面检查覆盖演示值 25%/75%、未知值、进度条范围、两种体型、三档缩放、气泡显示开关、左右墙/顶部/躲藏、尖角渲染和原有互动回归。
- 每日记录只包含时间、周用量百分比和额度桶/套餐标记，不读取或保存登录令牌及 credits 余额。接口没有日历史，首次启用和跨日停机后的读数标为部分记录；当天关闭期间若周窗口和读数连续，可从后续周增量继续统计。
- 精度限制：周累计值的服务端舍入和分钟级采样会影响日统计。账户切换若恰好具有相同套餐、相同周重置时间和连续上升读数，现有接口字段不能可靠区分，可能需要重新建立本地记录。混合 DPI 多屏仍未穷尽验证。

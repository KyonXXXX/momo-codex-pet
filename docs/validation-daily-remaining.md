# 今日剩余可用额度（本地 2.2.0-local）

按用户确认的口径，100% 等于周总额度的 1/7。使用账号周剩余额度与重置时间直接推算，不读取或写入旧的 daily-usage.json。

- 剩余 3 天、周剩 30%：今天可用周总量的 1.428571%，显示 10%。
- 剩余 3 天、周剩 60%：今天可用周总量的 20%，显示 140%。
- 剩余 3 天、周剩 10%：今天及下一天显示 0%，最后一天显示 70%。
- 额度日以周重置时间为锚点，每日 24 小时；相同账号快照与时刻在不同时区得到相同结果。
- 无数据、失效数据或离线跨额度日不发放虚构额度；同日离线结果有提示。

验证：.NET 8 SDK 8.0.425 Release 发布成功；26 项自检（含真实账号额度读取）全部通过。覆盖透支、结余、多电脑快照变化、无本机历史启动、跨日、时区、离线、非法数据和分配单调性。实际 WPF 渲染确认标签为「今日剩余可用」，数字与进度条显示正确；新增的 5 项显示断言通过。

完整界面捕获在既有 `bubble placed inward: MOVE/climb.right` 断言失败。未修改的已安装 v2.1.1 在同一电脑同样失败（241 项先前检查通过），确认此问题不由本次日额度逻辑引入。本次未修改爬墙行为。截图与报告保存在本地 artifacts 目录，未加入 Git。

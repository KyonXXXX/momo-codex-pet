# Momo 2.0 验证记录

环境：Windows，.NET 8 WPF，Release 构建。

- 官方固定版本：67 类动作、609 组、6,181 帧；3,755 个去重图片文件逐个验证 Git blob SHA-1。
- 全量动画：609 组通过实际播放器解码；64 个非分层动作族 × 4 种表情，256 项入口匹配通过；吃、喝、礼物通过 12 个分层配方另行验证。
- 逻辑自测：14 项通过，含旧设置兼容、默认状态、宠物金币与喂食、比例收益、缺失额度、精确余额及透明边界。
- 最终 WPF 互动回归：159 项通过。覆盖原有额度/贴边、分层投喂取消及一次扣费、工作计时一次结算、停止恢复、真实窗体走动/爬墙、提起动作切换、脸颊/身体命中及完整面板。
- 人工检查实际 WPF 渲染：互动、投喂、活动、图鉴四页以及吃饭、摸身体、捏脸、爬墙、网球、烧烤等代表性画面。头顶气泡保持原有尺寸，扩展信息在独立面板中。
- 全库解码压力测试观察到工作集约 355 MB；播放器限制缓存条目，避免把全部动画永久解码驻留。

完整库扫描的测试报告末尾曾有一个「提起动态」测试断言失败：测试构造了极端鼠标坐标，整数相加溢出。改为真实坐标附近的 100 px 位移后，最终动作回归全部通过。该修正不改动鼠标输入实现。

未全面覆盖：不同声卡/音频编码、实体音频输出、多显示器混合 DPI、Windows 所有版本。软件未宣称与 VPet 的 Steam、创意工坊或云功能兼容。

UI 审查：桌面中文页面可读，长清单滚动，额度气泡未增加永久数值；没有新增付费、广告或遥测。手机和 Google Play 审核不适用本 Windows 应用。
